# Cartella delle ninna nanne 🎵

Metti qui i tuoi file audio (4-5 ninna nanne). Formati accettati:
`.mp3`, `.wav`, `.ogg`, `.m4a`, `.aac`, `.flac`.

Il **nome del file** diventa il titolo mostrato nell'app. Esempio:

```
lullabies/
├── Ninna nanna della luna.mp3
├── Brahms.mp3
├── Twinkle twinkle.mp3
├── Suono bianco pioggia.mp3
└── Battito del cuore.mp3
```

Suggerimenti:
- Usa file **non troppo grandi** (l'audio viaggia sulla rete di casa).
- Attiva "ripeti" nell'app per farle suonare in loop.
- Le ninna nanne suonano dall'**altoparlante del dispositivo su cui apri l'app**
  (es. l'iPad vicino alla culla): è il modo più affidabile e 100% offline.

> Nota: i file audio non vengono caricati su git (vedi `.gitignore`).
> Restano solo sul tuo dispositivo.
